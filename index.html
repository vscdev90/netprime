Regio: Nederland (NL) · Releasedatums, niet noodzakelijk "toegevoegd op" datum · Gegevens via TMDB. Deze app maakt gebruik van de TMDB API, maar wordt niet onderschreven of gecertificeerd door TMDB.

TMDB API-key nodig

Deze app haalt releasegegevens op bij TMDB (The Movie Database). Je hebt een gratis API-key nodig.

  1. Maak een gratis account op themoviedb.org
  2. Ga naar Instellingen → API en vraag een "API Key (v3 auth)" aan
  3. Plak de key hieronder

De key wordt alleen lokaal in je browser opgeslagen (localStorage) en nergens anders naartoe gestuurd, behalve rechtstreeks naar TMDB.
